# Figures: Rect, Square, Circle (Kotlin)

Классы `Rect`, `Square`, `Circle` наследуются от `Figure` и реализуют интерфейсы `Transforming` (`resize`, `rotate`) и `Movable` (`move`).

## Допущения
- Ось Y направлена вверх.
- `x, y` у Rect и Square — левый нижний угол, у Circle — центр.
- `resize(zoom)` не сдвигает опорную точку, размеры умножаются на `zoom`.
- `rotate` поворачивает фигуру на 90° вокруг заданной точки.

## Демонстрация
Результат запуска `Main.kt`:

```
=== Исходное состояние ===
Rect(x=0, y=0, width=4, height=2)
Square(x=1, y=1, side=3)
Circle(x=5, y=5, radius=2)
Площади: 8.0, 9.0, 12.566371

=== Перемещение на (2; 3) ===
Rect(x=2, y=3, width=4, height=2)
Square(x=3, y=4, side=3)
Circle(x=7, y=8, radius=2)

=== Масштабирование x2 ===
Rect(x=2, y=3, width=8, height=4)
Square(x=3, y=4, side=6)
Circle(x=7, y=8, radius=4)
Площади: 32.0, 36.0, 50.265484

=== Поворот по часовой на 90° вокруг (0; 0) ===
Rect(x=3, y=-10, width=4, height=8)
Square(x=4, y=-9, side=6)
Circle(x=8, y=-7, radius=4)

=== Поворот против часовой на 90° вокруг (0; 0) (возврат) ===
Rect(x=2, y=3, width=8, height=4)
Square(x=3, y=4, side=6)
Circle(x=7, y=8, radius=4)
```

## Что видно из результата
- `move(2, 3)` сдвинул все фигуры на (+2; +3).
- `resize(2)` удвоил линейные размеры, площади выросли в 4 раза (8 → 32, 9 → 36, 12.57 → 50.27).
- `rotate` по часовой на 90° вокруг (0; 0) переместил фигуры, у прямоугольника поменялись местами ширина и высота. Поворот против часовой вернул исходные значения.
